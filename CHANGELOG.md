# 📋 Changelog

## [1.1.0] - 2024-11-18

### ✨ Добавлено

#### 🌐 FastAPI Health Checks
- **Поддержка HEAD запросов** на эндпоинтах `/` и `/health`
- Теперь внешние мониторы (UptimeRobot, Better Uptime) не получают ошибку 405
- Render health checks работают стабильно без логов ошибок

#### 📊 Улучшенное логирование

**При получении сообщения из Telegram:**
```
📨 Получено сообщение #12345 из @python_jobs (Python Jobs): "Требуется Python-разработчик для..."
```

**При фильтрации:**
```
⏭️  Сообщение #12345 уже обработано ранее (дубликат в БД)
🗑️  Сообщение #12346 отфильтровано: слишком короткое (15 < 20 символов)
🗑️  Сообщение #12347 отфильтровано: стоп-слова ['плюс', '+']
✅ Сообщение #12348 прошло фильтры и добавлено в очередь для AI-анализа
```

**При AI-анализе:**
```
🔄 Worker 0 обрабатывает сообщение #12348
🤖 Отправляю сообщение #12348 на анализ в OpenAI: "Требуется Python-разработчик..."
🎯 Найдено релевантное сообщение #12348: order, 85%
📉 Сообщение #12349 не прошло фильтр: type=flood, relevance=25%
```

**Преимущества нового логирования:**
- 🔍 **Прозрачность**: видно каждый этап обработки
- 🐛 **Отладка**: легко найти причину отсева сообщений
- 📈 **Мониторинг**: можно отслеживать эффективность фильтров
- 🎨 **Эмодзи-маркеры**: быстрая визуальная идентификация типов событий

### 🔧 Изменено

#### Метод `on_new_message`:
- Добавлено логирование получения каждого сообщения
- Показывается название/ID чата и превью текста (50 символов)
- При фильтрации указывается конкретная причина отсева
- Улучшены сообщения об ошибках с эмодзи

#### Метод `worker`:
- Добавлено логирование перед отправкой в OpenAI
- Показывается превью текста сообщения (100 символов)
- Улучшена читаемость логов результатов анализа
- Добавлены эмодзи для визуальной идентификации

#### FastAPI эндпоинты:
- `GET /` и `HEAD /` - корневой health check
- `GET /health` и `HEAD /health` - расширенный health check
- `GET /stats` - статистика работы бота

### 🛡️ Безопасность

Без изменений:
- ✅ StringSession поддержка сохранена
- ✅ Дедупликация через SQLite работает
- ✅ Первичная фильтрация спама активна
- ✅ Rate limiting с паузами 0.5-2 сек

### 📦 Зависимости

Без изменений - все зависимости остались прежними.

## [1.0.0] - 2024-11-18

### ✨ Первый релиз

**Основные возможности:**
- Producer-Consumer архитектура через asyncio.Queue
- Telethon userbot для мониторинга каналов
- Первичная фильтрация мусора (< 20 символов, стоп-слова)
- Дедупликация через SQLite
- AI-анализ через OpenAI GPT-4o-mini
- Уведомления через aiogram
- FastAPI веб-сервер для Render
- StringSession поддержка для деплоя

**Компоненты:**
- `main.py` - основной файл бота
- `generate_session.py` - генератор StringSession
- `requirements.txt` - зависимости
- `Procfile` - команда запуска для Render
- `render.yaml` - конфигурация деплоя
- `.env.example` - шаблон переменных окружения

**Документация:**
- `README.md` - основная документация
- `SESSION_GUIDE.md` - гайд по StringSession
- `PROJECT_SUMMARY.md` - краткая сводка проекта

## Миграция с 1.0.0 на 1.1.0

### Шаги:

1. **Обновите код:**
   ```bash
   git pull origin main
   ```

2. **Перезапустите бот:**
   ```bash

   python main.py
   
   # На Render
   ```
